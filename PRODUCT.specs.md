# PRODUCT.specs.md

The only file you fill in for a new project. It describes the product. It does not mention frameworks, libraries, accounts, or program layout. The template decides all of that.

```markdown
# <Name>
- Ticker:
- Pitch: one line
- Who it's for:

## What it does
- <thing a person can do, in plain words, and the rule behind it>

## Screens
- Landing: <sections you want>
- /app: <what the screen lets someone do>

## Look
- Mood: 3 to 5 words
- Color: <optional hex>
- References: <optional, a site or a feeling>
- 3D: <optional, one sentence describing the object>

## Voice
- X handle:
- Language: English
- Tone: <a few words>
```

Empty fields fall back to the template defaults.
